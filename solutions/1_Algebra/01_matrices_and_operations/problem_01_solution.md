## Matrix Dimensions and Entries

### Matrix $A$

* **Size:** $2 \times 3$ (2 rows and 3 columns)
* **Entries:**
* **Row 1:** $2, -1, 3$ (e.g., $a_{11} = 2$, $a_{12} = -1$, $a_{13} = 3$)
* **Row 2:** $0, 4, 5$ (e.g., $a_{21} = 0$, $a_{22} = 4$, $a_{23} = 5$)



### Matrix $B$

* **Size:** $3 \times 2$ (3 rows and 2 columns)
* **Entries:**
* **Row 1:** $1, 0$ (e.g., $b_{11} = 1$, $b_{12} = 0$)
* **Row 2:** $-2, 3$ (e.g., $b_{21} = -2$, $b_{22} = 3$)
* **Row 3:** $4, 1$ (e.g., $b_{31} = 4$, $b_{32} = 1$)
